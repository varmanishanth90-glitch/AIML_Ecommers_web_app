# 🛍 AIML E-Commerce Web App

This project is a **Shopping Assistant Bot** built with Flask, MySQL (AWS RDS), and AWS S3.  
It allows users to search products, view images, and compare multiple products side-by-side.

---

## 🚀 Features
- Full-screen shopping assistant UI
- Product search powered by MySQL RDS
- Product images served securely from AWS S3
- Compare **2–4 products** with details:
  - Image
  - Name
  - Price
  - Category
  - Subcategory
